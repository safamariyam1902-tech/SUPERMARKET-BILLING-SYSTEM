# 🧾 Bill Discount Calculator in Python

## 📌 Project Description

The **Bill Discount Calculator** is a simple Python program that calculates the final bill amount based on the original purchase amount.

Customers who purchase for ₹2,000 or more receive a **10% discount**. If the purchase amount is less than ₹2,000, no discount is applied.

This project demonstrates basic Python programming concepts, including conditional statements, arithmetic operations, user input, and exception handling.

## ✨ Features

- 💰 Accepts the original bill amount from the user.
- 🎉 Provides a 10% discount on purchases of ₹2,000 or more.
- 🧮 Calculates the discount and final bill amount.
- ⚠️ Validates the bill amount to ensure it is greater than zero.
- 🚫 Handles invalid inputs using `try-except`.
- ✅ Displays a bill summary with the original amount, discount, and final amount.
- 🔚 Uses `else` and `finally` blocks for program flow and completion messages.

## 🛠️ Technologies Used

- **Language:** Python 3
- **Concepts:** Variables, `if-else` conditions, arithmetic operations, `try-except-else-finally`, and user input validation.

## 📋 Discount Rules

| Original Bill Amount | Discount |
|---|---|
| ₹2,000 or more | 10% |
| Less than ₹2,000 | No discount |
| Zero or negative amount | Invalid amount |
